# Хөдөлмөрийн тухай хуулийн RAG чатбот (локал, Монгол хэл)

**English TL;DR.** A fully local Retrieval-Augmented Generation (RAG) assistant for the Mongolian Labor Law
(166 articles, Cyrillic Mongolian). Article/clause-aware chunking, hybrid retrieval (Qwen3-Embedding + BM25 with RRF),
clause-level context selection, number/exception guards, and a three-tier evaluation protocol (tuning, dev, sealed final).
Runs on a laptop with 4 GB VRAM via [Ollama](https://ollama.com). It is a research prototype, **not legal advice**.

---

## Юу хийдэг вэ

Хөдөлмөрийн тухай хуулийн (шинэчилсэн найруулга) талаар Монгол хэлээр асуухад холбогдох заалтыг олж, **зөвхөн тэр
заалтад тулгуурлан** хариулж, иш татсан зүйлийн дугаарыг заана. Хуульд байхгүй зүйлийг асуувал "Мэдээлэл олдсонгүй" гэж
хэлэхийг оролддог. Бүх тооцоо өөрийн компьютер дээр явагдана (интернэт, гадаад API хэрэггүй).

```
> ээлжийн амралтаа эдэлж чадаагүй бол нэмэлтээр юу авах вэ?

Хариулт: Ажилтан ажлын зайлшгүй шаардлагаар ээлжийн амралтаа биеэр эдэлж чадаагүй бол түүнд ээлжийн
амралтын цалинг нэг аравны тав дахин нэмэгдүүлж олгоно (Зүйл 110.2).
```

## Үр дүн

Асуултуудыг гурван түвшинд хуваасан. **Зөвхөн эцсийн багцыг гүйцэтгэлийн үзүүлэлт гэж үз**: тохируулалтын багц дээр
системийг тааруулсан тул 100% гарсан.

| Багц | Зориулалт | Хайлт hit@1 / hit@3 / hit@5 | Хуульд байгаа асуултын зөв хариулт | Хуульд байхгүйг зөв татгалзсан |
|---|---|---|---|---|
| `eval_set.json` (29+3) | Тохируулалт | 100% / 100% / 100% (тааруулсан) | - | - |
| `eval_holdout.json`, `eval_dev2.json` (27+8) | Хөгжүүлэлт | 74% / 93% / 93% (0.6B) | 85% (23/27) | 75% (6/8) |
| `eval_final.json` (12+6) | **Эцсийн, нэг л удаа ажиллуулсан** | 92% / 92% / 100% (4B) | 75% (9/12) скриптээр, 83% (10/12) гараар | 33% (2/6) скриптээр, 50% (3/6) гараар |

Анхаарах зүйл:

- Дээж жижиг тул итгэх завсар өргөн (жишээ нь эцсийн хайлт hit@1 92%, 95%-ийн завсар 65-99%).
- Хуульд байхгүй асуултын татгалзал сул: холбоотой үгтэй асуултад ("утасны төлбөр") модель хамааралгүй заалтаас
  хариулт зохиодог.
- "Гараар" гэсэн тоо нь хариултыг утгаар нь уншиж үнэлсэн тоо; "скриптээр" нь түлхүүр үг + зөв Зүйл иш татсан эсэх шалгалт.

## Шаардлага

- Python 3.10+
- [Ollama](https://ollama.com/download)
- Туршсан орчин: Windows, RTX 3050 (4 GB VRAM), 8 GB RAM. Хариулт 8-55 секунд.

## Суулгах

```bash
# 1. Загваруудыг татах
ollama pull qwen3.5:4b
ollama pull qwen3-embedding:0.6b      # хурдан. Эцсийн тоог 4b-ээр хэмжсэн: ollama pull qwen3-embedding:4b

# 2. Python орчин
python -m venv venv
source venv/Scripts/activate          # Windows Git Bash. Linux/Mac: source venv/bin/activate
pip install -r requirements.txt
```

`Rag.py`-ийн дээд хэсэгт тохиргоо бий (`EMBED_MODEL`, `LLM_MODEL`, `MAX_CHARS`, `FOCUS_TOP`, `CLAUSE_DENSE` гэх мэт).

## Ажиллуулах

```bash
export PYTHONUTF8=1                   # Windows дээр Кирилл зөв харагдуулна
python chat.py                        # асуулт хариулт
python chat.py --debug                # моделд очсон контекстийг харуулна
```

Эхний ажиллуулалтад хуулийн 371 хэсгийг embedding болгож `index_cache/` дотор хадгална (хэдэн минут). Дараагийн
удаа тэндээс уншина.

## Үнэлгээ

```bash
python eval_retrieval.py --set eval_holdout.json --answers
python eval_retrieval.py --set eval_dev2.json --answers
python eval_retrieval.py --set eval_final.json --answers     # ЭЦСИЙН: үр дүнг тайлагнасны дараа дахин бүү тохируул
```

Скрипт нь hit@k, MRR, хариултын түлхүүр үг + зөв Зүйл иш татсан эсэхийг тооцож, 95%-ийн итгэх завсартайгаар (Вилсон)
харуулна. Асуулт бүрийн зөв заалт, хариултын түлхүүр үгийг хуулийн текстээр баталгаажуулсан.

## Хэрхэн ажилладаг вэ

1. **Хэсэглэлт:** хуулийг зүйл, заалтын хилээр ≤600 тэмдэгтээр хувааж, хэсэг бүрийн эхэнд "Зүйл N. гарчиг" давтана.
2. **Hybrid хайлт:** Qwen3-Embedding (косинус) + BM25 (үгийн эхний 4 үсэг, Монгол хэлний нөхцөлд зориулсан), RRF-ээр нэгтгэнэ.
3. **Контекст сонголт:** олдсон зүйлүүдээс хамгийн холбоотой 5 заалтыг сонгоно. Загвар "олдсонгүй" гэвэл эсвэл тоо
   баталгаажихгүй бол контекстыг томруулж дахин оролдоно.
4. **Хариулт:** Qwen3.5 4B (thinking унтраасан, temperature 0).
5. **Хамгаалалт:** сэдвийн шалгалт, тусгай бүлгийн (насанд хүрээгүй, жирэмсэн...) заалтын шүүлт, хариултын тоог
   контекстээр баталгаажуулах (бутархай хэллэгийг оролцуулан).

## Мэдэгдэж буй хязгаарлалт

- Хуульд байхгүй асуултад хуурамч хариулт зохиох (эцсийн багцад 6-аас 3).
- Заалтын утгыг эсрэгээр хөрвүүлэх, "…-аас бусад тохиолдолд" гэсэн нөхцөлийг орхих тохиолдол бий.
- Ярианы хэллэг ба хуулийн хэллэгийн зөрүү ("халах" vs "цуцлах") хайлтад саад болдог.
- 4B загварын Монгол хэл дээр заримдаа утгагүй, үг залгагдсан өгүүлбэр гарна.
- Хуулийн текстийг цэвэрлэхэд 12 газарт дэд бүлгийн гарчиг заалтын төгсгөлд наалдсан хэвээр үлдсэн.
- Үнэлгээний асуултуудыг зохиогч өөрөө бичсэн, дээж жижиг.

Иймээс энэ нь **лавлах туслах**. Хариултыг үргэлж иш татсан заалтын эх текстээр шалга. **Хуулийн зөвлөгөө биш.**
